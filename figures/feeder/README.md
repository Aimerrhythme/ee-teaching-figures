# 10 kV 辐射式馈线单线图

## 用途
供配电技术 / 电力系统基础里「配电网接线方式」一节：讲辐射式（放射式）馈线的结构、分段与联络，以及故障隔离和转供的思路。可放进课件或板书投影。

## 图中符号与含义
- 左：110 kV 系统经主变（110/10 kV）接到变电站 10 kV 母线（粗竖线）。
- QF1：本馈线出线断路器（实心方块），能开断短路电流，配合继电保护跳闸。QF2 只画出示意，代表母线上的其他出线。
- 主干线：S1、S2 为分段开关（实心圆，正常闭合），把主干分成三段。
- 分支：每个 T 接点经熔断器 FU1–FU3 接配电变压器 T1–T3（10/0.4 kV，双圆符号），再到负荷 L1–L3（箭头）。
- 末端：联络开关 QS（红色空心圆，正常断开），虚线通往相邻馈线。
- 蓝色箭头：正常运行时潮流从母线单向流向末端。

## 课堂可讲的要点
- 辐射式：正常只有一个电源方向供电，结构简单、保护好配合，但可靠性受单一路径限制。
- 故障隔离：若 S1 与 S2 之间发生故障，QF1 跳闸后断开 S1、S2，合上 QF1 恢复第一段；再合 QS 由相邻馈线向第三段转供，只有中间段停电。
- 熔断器只保护分支，分支故障不应使 QF1 跳闸（讲选择性时可用）。

## 可修改处
- 分支数目、开关编号可按例题增删；可在各段旁标注线路长度、导线型号或负荷功率。
- 讲「手拉手」环网时，可再画一条从右侧来的馈线，与 QS 对接。
- 开关符号按本仓库图例自定，与国标图形符号不完全一致；正式图纸请按 GB/T 4728 绘制。
