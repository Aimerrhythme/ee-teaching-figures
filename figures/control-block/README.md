# 单闭环负反馈控制框图

## 用途
自动控制原理 / 电机与拖动控制 / 电力电子控制里「闭环控制系统的组成」一节：讲给定、比较、控制器、被控对象、检测反馈各环节的作用，以及负反馈怎样减小偏差。可作为后续画双闭环（电流内环 + 转速外环）框图的通用起点。

## 图中符号与含义
- R(s)：给定（参考）输入；Y(s)：系统输出（被控量）。
- 带叉圆圈：比较环节，左侧 +、下方红色 − 表示负反馈，输出偏差 E(s) = R(s) − B(s)。
- Gc(s)：控制器（如 P、PI、PID），输出控制量 U(s)。
- 小圆圈 + 虚线 D(s)：作用在被控对象输入侧的扰动，讲抗扰性时使用，不讲时可删去。
- Gp(s)：被控对象（如电机、电源变换器、温控炉）。
- 蓝色通道：反馈通道，H(s) 为检测/反馈环节（传感器、测速机、电流互感器等），输出反馈信号 B(s) = H(s)·Y(s)。
- 底部公式：D = 0 时的闭环传递函数 Φ(s) = Gc·Gp / (1 + Gc·Gp·H)。

## 课堂可讲的要点
- 开环传递函数 Gc·Gp·H 与闭环传递函数的区别；单位反馈时 H = 1。
- 当 |Gc·Gp·H| 很大时，Φ(s) ≈ 1/H：闭环特性主要由反馈环节决定，所以检测精度很关键。
- 扰动到输出的传递函数 Y/D = Gp / (1 + Gc·Gp·H)：回路增益越大，扰动影响越小。

## 可修改处
- 把 Gc(s)、Gp(s)、H(s) 替换为具体表达式（如 Kp(1 + 1/(Ti·s))、K/(Ts + 1)）做例题。
- 扰动也可改画在输出端（Y 侧相加），对比两种位置的抗扰效果。
- 文件为纯 SVG 文本，用任意文本编辑器或 Inkscape 修改文字即可。
