# 单相变压器结构与 T 型等效电路

## 用途
电机学（或电力系统基础）里「单相双绕组变压器」一节：先看心式结构，再对照折算到一次侧的 T 型等效电路。可放进课件或板书投影。

## 图中符号与含义
- 左：口字形铁心；蓝圈为一次绕组 N₁，红圈为二次绕组 N₂。黑点是同名端。
- 按图中所设正方向：I₁ 从同名端流入，I₂ 从同名端流出（一次吸收、二次送出）。
- Φₘ：铁心主磁通，沿铁心闭合。箭头只表示示意方向，漏磁通没有画出。
- 变比 k = N₁/N₂。
- 右：T 型等效电路。一横是一次、二次漏阻抗，中间竖枝是励磁支路。
- R₁、X₁σ：一次绕组电阻、一次漏抗。
- Rₘ ∥ jXₘ：励磁电阻与励磁电抗并联。I₀ 分成铁耗电流 I_Fe 与磁化电流 I_μ。支路电压为 E₁。
- R′₂、X′₂σ、U′₂、I′₂、Z′_L：二次侧各量折算到一次侧之后的值。
- I₁ = I₀ + I′₂。
- 折算关系：R′₂ = k²R₂，X′₂σ = k²X₂σ，U′₂ = kU₂，I′₂ = I₂/k。

## 可修改处
- 各元件旁可加课堂例题中的数值（如 R₁、Xₘ）。
- 同名端黑点与 Φₘ、I₁、I₂ 箭头可按所设正方向改动，改完后核对「流入 / 流出同名端」是否仍一致。
- 负载框可改成纯电阻或具体阻抗；讲 Γ 型近似时，可把励磁支路移到电源端并在图上注明。
